Manual

This is the manual for the Procedraw graphing language. If anything in this manual is incorrect/confusing, please create a bug report on GitHub (link) or tell me directly (you know how to if you know me).

Structure

Operations

  • Precedence 1:
    • + Addition Usage: a + b
    • - Subtraction Usage: a - b
  • Precedence 2:
    • * Multiplication Usage: a * b
    • / Division Usage: a / b
  • Precedence 3:
    • - Negate Usage: -x
    • & Bitwise AND Usage: a & b
    • | Bitwise OR Usage: a | b
    • @ Bitwise XOR Usage: a @ b

The precedence of an operator determines which operation is done first. The lower the precedence, the later an operation is done. Example: 1 + 2 * 3. 2 * 3 will happen first, because addition has a lower precedence than multiplication. If multiple operators have the same precedence, then each operation is done from left to right.

Functions

A function is called like: functionName(arg1, arg2, arg3...)

An argument is a value passed into the function when calling it. Multiple arguments must be separated with commas.

Examples: 1 argument: sqrt(2) 2 arguments: mod(x, 1) Functions in functions: sin(atan2(x, y) * 4)

Built-in Functions

  • sqrt(x) Negative values of x return NaN.
  • cbrt(x)
  • mod(dividend, divisor) Returns the unsigned (always positive) remainder of a / b.
  • rem(dividend, divisor) Returns the signed (negative or positive) remainder of a / b.
  • pow(b, e) Returns be
  • floor(x) Returns the whole number closest to x towards -Infinity.
  • round(x) Returns the whole number closest to x towards 0.
  • ceil(x) Returns the whole number closest to x towards Infinity.
  • abs(x) Returns the distance of x to 0.
  • min(a, b) Returns a if a < b, b if b < a.
  • max(a, b)

  • sin(theta)
  • cos(theta)
  • tan(theta)
  • asin(x)
  • acos(x)
  • atan(x)
  • atan2(x, y) Returns the angle of (x, y) from (0, 0)
